The engine, running in this page

Every figure below is computed right now, in your browser, by the same TypeScript engine the platform runs on the server. Nothing is pre-rendered and nothing is mocked — pick a property and the cash flow is recalculated from its assumptions.

Engine — 34 significant digits, half-even 20 regression fixtures 589 tests · 117 browser tests

This is the engine, not the platform. The full application has a PostgreSQL database, authentication with a second factor, an audit log, imports, reports and multi-user permissions — none of which can run in a static page.

The engine is the part with no server dependency, so it is the part that can be shown honestly this way. There is no hosted deployment of the whole platform: its container images have never been built, which is recorded as a release blocker rather than glossed.

Why these numbers can be trusted

The regression library holds twenty independently designed properties, and no expected value in it was produced by running the engine and copying the output. Each is either derived by hand from the fixture's own assumptions, or recomputed in the test by a different method than the engine uses — a closed-form geometric annuity against the engine's per-period loop, a closed-form remaining-balance formula against its amortisation schedule.

A test built from the engine's own output agrees with the engine by construction. It would pass on the day a formula silently breaks.

What the full platform adds

  • Persistence and versioning — immutable model versions, so a valuation issued last quarter still reproduces exactly.
  • Traceability — every figure on the real cash-flow grid opens an inspector showing how the engine derived it.
  • Rent roll and imports — CSV and Excel, with header detection, column mapping and validation before anything is written.
  • Portfolio and fund roll-ups — rates rebuilt from the portfolio's own numerator and denominator, never averaged across assets.
  • Budgets, variance and asset management — trial-balance import, materiality thresholds, commentary that cannot be approved by its own author.
  • Access control — nine roles, capability-checked on every one of 116 routes, with two-factor authentication.

What the engine deliberately does not model

Each of these raises a named diagnostic rather than producing a number nobody should act on. A model that says I cannot answer this is worth more than one that guesses.

  • Expansion options — the option records how much area is taken but not which space it comes from, so honouring it would either double-count area or invent floor space the property does not have.
  • Cash sweep — applying trapped cash to principal makes the schedule depend on the cash flow that depends on the schedule.
  • Fund-level carry and recallable distributions — documented as unmodelled in the investor statement's own footnotes.
  • Yield capitalisation — term and reversion, hardcore and equivalent yield are not implemented.
